# Ferrara Bookkeeping & Consulting Website

Repository structure for a Next.js App Router website deployed with Cloudflare Pages. This scaffold separates routing, reusable UI, structured registries, and owner-approved copy.

## Stack

- Next.js App Router + TypeScript
- Claude Code and VS Code for implementation
- GitHub for version control
- Cloudflare Pages for deployment

## Content workflow

Add approved business copy to `content/` before wiring it into page components. Treat registry metadata as routing/build data, not permission to publish a page. Matrix URLs should only be enabled once their audience-specific content is reviewed.

Project governance, architecture, keyword/metadata rules, schemas, and launch gates are documented in [`docs/README.md`](docs/README.md). Read that index and applicable docs before implementation.
